# Hyperparameter Visualization in Generative ML Models 

## Project Overview

Developed an interactive platform to visualize the impact of hyperparameter variations in generative machine learning models. The project aims to enhance model interpretability and assist in better decision-making by exploring how changes in hyperparameters influence the generated outputs.

## Key Features

- **Hyperparameter Variation**: Explored the effect of different hyperparameter settings (learning rates, batch sizes, weight decay) on model behavior and output.
- **Visualization Tools**: Used heatmaps, latent space projections, and output grids to represent the model’s performance under different configurations.
- **Improved Interpretability**: Aimed to improve the understanding of generative model dynamics, optimizing their performance and decision-making process.

## Technologies Used

- **Python** (for scripting and machine learning tasks)
- **TensorFlow/PyTorch** (for training and generating models)
- **Matplotlib/Seaborn** (for plotting heatmaps and visualizations)
- **Scikit-learn** (for optimization and evaluation)
- **React** (for building an interactive visualization interface)

## How It Works

1. **Model Training**: Trains a generative model using various hyperparameter settings.
2. **Visualization**: Displays results through interactive visualizations such as heatmaps, projections, and output grids.
3. **Hyperparameter Adjustment**: Users can adjust hyperparameters in real-time to observe the changes in model output.
